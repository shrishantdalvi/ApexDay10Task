# Apex Lark – Day 10: Superstore Business Analysis Dashboard

## Project Overview
This project focuses on analysing Superstore sales data using Python and building a consolidated business dashboard. The objective is to identify important business trends and present key performance indicators through visualisations.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- HTML
- CSS
- VS Code

## Key Performance Indicators (KPIs)
The dashboard includes seven important KPIs:

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Total Products
- Profit Margin (%)
- Average Order Value (AOV)

## Business Analysis

### Sales Analysis
- Monthly Sales Trend
- Sales by Region
- Sales by Category

### Customer Analysis
- Top 10 Customers by Sales

### Product Performance
- Top 10 Products by Sales

### Profit Analysis
- Profit by Category
- Profit by Region

### Advanced Visualization
- Correlation Heatmap

## Key Business Findings
- **Highest Sales Category:** Technology
- **Highest Sales Month:** November 2017
- **Highest Revenue Region:** West
- **City with Highest Order Count:** New York City
- **Most Profitable Customer Segment:** Consumer

## Dashboard Features
- Seven KPI summary cards.
- Multiple business analysis sections.
- Integrated chart images in a single HTML dashboard.
- Navy-blue dashboard theme with cyan highlights.
- Responsive layout for different screen sizes.
- Separate chart cards for organised data presentation.

## Business Recommendations
1. Strengthen sales strategies in the West region and explore opportunities in other regions.
2. Focus on Technology category performance while monitoring profitability.
3. Analyse the November 2017 sales peak to understand monthly demand patterns.
4. Use customer and city-level insights for targeted marketing strategies.
5. Monitor sales, profit and profit margin together to support better business decisions.

## Project Deliverables
- Jupyter Notebook (`.ipynb`)
- HTML Business Dashboard (`KPI_Dashboard.html`)
- Business Insights Report (`Day_10_Business_Insights_Report.pdf`)
- Chart images stored in the `output` folder.

## Conclusion
The project demonstrates how Python-based data analysis and visualisation can transform raw Superstore data into meaningful business insights. The integrated dashboard provides a structured overview of sales, customer, product and profitability performance, supporting data-driven business decisions.
